## 🎯 **What HerEducation Actually Does**

HerEducation is a **7-page Streamlit application** that combines YouTube comment analysis, UNESCO education data visualization, and cross-country discourse comparison in one comprehensive platform.

### **The 7 Main Applications:**

1. **📖 Project Introduction** - Interactive storytelling about education equality in Malaysia
2. **🗺️ UNESCO Dashboard** - Education data visualization for 196 countries  
3. **📊 Indicators Development** - Educational progress tracking 2019-2025
4. **🎥 YouTube Analyzer** - Video search, audio download & Whisper transcription
5. **💬 German Comment Analysis** - Complete NLP pipeline for German YouTube comments
6. **💬 English Comment Analysis** - Complete NLP pipeline for English YouTube comments  
7. **🌍 Global Discourse Analysis** - Cross-country comment comparison with automatic country detection
