**© 2025 Sandra Störkel - Advanced Data Science Portfolio Project**

> *A comprehensive platform for intelligent analysis of YouTube comments and audio content, developed to promote educational equity and better understanding of online educational discourse through advanced NLP and ML techniques.*

## 🚀 **Quick Start**

### Prerequisites
- Python 3.8+
- 4GB RAM (8GB recommended for large analyses)
- Internet connection for ML model downloads

### Installation
```bash
git clone https://github.com/yourusername/HerEducation.git
cd HerEducation
pip install -r requirements.txt
streamlit run main.py
```

### First Steps
1. **Open Streamlit interface** (opens automatically in browser)
2. **Load demo data** or upload your own CSV files
3. **Select analysis type** (Sentiment, Emotion, Topics, Audio)
4. **Explore results** interactively and export findings
